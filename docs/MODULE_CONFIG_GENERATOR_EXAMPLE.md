# Module Config Generator - Implementation Example

## Overview

This document shows how to implement `IModuleConfigGenerator` in a module to enable automatic configuration file generation during system startup.

## Interface Definition

```csharp
public interface IModuleConfigGenerator
{
    Task<ModuleConfigGenerationResult> GenerateConfigAsync(
        IModuleContext context, 
        CancellationToken cancellationToken);
    
    IEnumerable<string> GetConfigFilePaths();
    
    bool RequiresServiceRestart { get; }
}
```

## Example: DHCP Server Config Generator

Here's a complete example for a DHCP server module:

```csharp
using Monolith.FireWall.Common.Interfaces;
using System.Text;

namespace MonolithNetwork.Modules.Dhcp;

public class DhcpModule : IMonolithModule, IModuleConfigGenerator
{
    // ... IMonolithModule implementation ...

    // IModuleConfigGenerator implementation
    public bool RequiresServiceRestart => true;

    public IEnumerable<string> GetConfigFilePaths()
    {
        return new[]
        {
            "/etc/dhcp/dhcpd.conf",
            "/etc/default/isc-dhcp-server"
        };
    }

    public async Task<ModuleConfigGenerationResult> GenerateConfigAsync(
        IModuleContext context, 
        CancellationToken cancellationToken)
    {
        var result = new ModuleConfigGenerationResult
        {
            Success = false
        };

        try
        {
            context.Logger.LogInformation("Generating DHCP server configuration...");

            // Step 1: Read DHCP settings from database
            // (Assuming you have a DhcpSettingsStore or similar)
            var dhcpSettings = await GetDhcpSettingsFromDatabaseAsync(context);
            if (dhcpSettings == null)
            {
                result.Error = "No DHCP settings found in database";
                return result;
            }

            // Step 2: Generate dhcpd.conf
            var dhcpdConf = GenerateDhcpdConf(dhcpSettings);
            var dhcpdConfPath = "/etc/dhcp/dhcpd.conf";
            
            // Ensure directory exists
            var dhcpdDir = Path.GetDirectoryName(dhcpdConfPath);
            if (!string.IsNullOrEmpty(dhcpdDir))
            {
                Directory.CreateDirectory(dhcpdDir);
            }

            // Write config file
            await File.WriteAllTextAsync(dhcpdConfPath, dhcpdConf, cancellationToken);
            result.GeneratedFiles.Add(dhcpdConfPath);
            context.Logger.LogInformation($"Generated: {dhcpdConfPath}");

            // Step 3: Generate isc-dhcp-server defaults
            var iscDefaults = GenerateIscDefaults(dhcpSettings);
            var iscDefaultsPath = "/etc/default/isc-dhcp-server";
            await File.WriteAllTextAsync(iscDefaultsPath, iscDefaults, cancellationToken);
            result.GeneratedFiles.Add(iscDefaultsPath);
            context.Logger.LogInformation($"Generated: {iscDefaultsPath}");

            // Step 4: Validate configuration (optional but recommended)
            var validationResult = await ValidateDhcpConfigAsync(context, dhcpdConfPath);
            if (!validationResult.Success)
            {
                result.Error = $"DHCP config validation failed: {validationResult.Error}";
                return result;
            }

            result.Success = true;
            result.RequiresRestart = true; // DHCP service needs restart
            result.Metadata["interfaces"] = string.Join(",", dhcpSettings.Interfaces);
            result.Metadata["subnets"] = dhcpSettings.Subnets.Count;

            context.Logger.LogInformation("DHCP configuration generated successfully");
        }
        catch (Exception ex)
        {
            result.Error = ex.Message;
            context.Logger.LogError(ex, "Failed to generate DHCP configuration");
        }

        return result;
    }

    private string GenerateDhcpdConf(DhcpSettings settings)
    {
        var sb = new StringBuilder();
        
        // IMPORTANT: Always include Monolith marker for file management
        sb.AppendLine("# BEGIN MONOLITH MANAGED");
        sb.AppendLine("# Generated by Monolith FireWall");
        sb.AppendLine($"# Generated at: {DateTime.UtcNow:O}");
        sb.AppendLine("# Do not edit this file manually - it will be regenerated on boot");
        sb.AppendLine();
        
        // Global options
        sb.AppendLine("option domain-name \"" + settings.DomainName + "\";");
        sb.AppendLine("option domain-name-servers " + string.Join(", ", settings.DnsServers) + ";");
        sb.AppendLine("default-lease-time " + settings.DefaultLeaseTime + ";");
        sb.AppendLine("max-lease-time " + settings.MaxLeaseTime + ";");
        sb.AppendLine();
        
        // Subnet declarations
        foreach (var subnet in settings.Subnets)
        {
            sb.AppendLine($"subnet {subnet.Network} netmask {subnet.Netmask} {{");
            sb.AppendLine($"  range {subnet.RangeStart} {subnet.RangeEnd};");
            
            if (!string.IsNullOrEmpty(subnet.Router))
            {
                sb.AppendLine($"  option routers {subnet.Router};");
            }
            
            if (!string.IsNullOrEmpty(subnet.Broadcast))
            {
                sb.AppendLine($"  option broadcast-address {subnet.Broadcast};");
            }
            
            sb.AppendLine("}");
            sb.AppendLine();
        }
        
        // Static leases
        foreach (var lease in settings.StaticLeases)
        {
            sb.AppendLine($"host {lease.Hostname} {{");
            sb.AppendLine($"  hardware ethernet {lease.MacAddress};");
            sb.AppendLine($"  fixed-address {lease.IpAddress};");
            sb.AppendLine("}");
            sb.AppendLine();
        }
        
        // End marker
        sb.AppendLine("# END MONOLITH MANAGED");
        
        return sb.ToString();
    }

    private string GenerateIscDefaults(DhcpSettings settings)
    {
        var sb = new StringBuilder();
        // IMPORTANT: Include Monolith marker
        sb.AppendLine("# BEGIN MONOLITH MANAGED");
        sb.AppendLine("# Generated by Monolith FireWall");
        sb.AppendLine($"# Generated at: {DateTime.UtcNow:O}");
        sb.AppendLine("# Do not edit this file manually");
        sb.AppendLine();
        sb.AppendLine("INTERFACESv4=\"" + string.Join(" ", settings.Interfaces) + "\"");
        sb.AppendLine("INTERFACESv6=\"\"");
        sb.AppendLine("# END MONOLITH MANAGED");
        return sb.ToString();
    }

    private async Task<DhcpSettings?> GetDhcpSettingsFromDatabaseAsync(IModuleContext context)
    {
        // Example: Use platform executor to query database via Core API
        // Or use a direct database connection if your module has access
        
        // For now, return example settings
        return new DhcpSettings
        {
            DomainName = "local",
            DnsServers = new[] { "8.8.8.8", "8.8.4.4" },
            DefaultLeaseTime = 3600,
            MaxLeaseTime = 7200,
            Interfaces = new[] { "eth0" },
            Subnets = new List<DhcpSubnet>
            {
                new DhcpSubnet
                {
                    Network = "192.168.1.0",
                    Netmask = "255.255.255.0",
                    RangeStart = "192.168.1.100",
                    RangeEnd = "192.168.1.200",
                    Router = "192.168.1.1",
                    Broadcast = "192.168.1.255"
                }
            },
            StaticLeases = new List<DhcpStaticLease>()
        };
    }

    private async Task<(bool Success, string? Error)> ValidateDhcpConfigAsync(
        IModuleContext context, 
        string configPath)
    {
        // Use platform executor to run dhcpd config test
        try
        {
            var result = await context.PlatformExecutor.ExecuteAsync(new PlatformRequest
            {
                Action = "platform.command.run",
                Command = new PlatformCommand
                {
                    FileName = "dhcpd",
                    Arguments = $"-t -cf {configPath}",
                    UseSudo = false
                }
            });

            return (result.Success, result.Error?.Message);
        }
        catch (Exception ex)
        {
            return (false, ex.Message);
        }
    }
}

// Example data models
public class DhcpSettings
{
    public string DomainName { get; set; } = string.Empty;
    public string[] DnsServers { get; set; } = Array.Empty<string>();
    public int DefaultLeaseTime { get; set; }
    public int MaxLeaseTime { get; set; }
    public string[] Interfaces { get; set; } = Array.Empty<string>();
    public List<DhcpSubnet> Subnets { get; set; } = new();
    public List<DhcpStaticLease> StaticLeases { get; set; } = new();
}

public class DhcpSubnet
{
    public string Network { get; set; } = string.Empty;
    public string Netmask { get; set; } = string.Empty;
    public string RangeStart { get; set; } = string.Empty;
    public string RangeEnd { get; set; } = string.Empty;
    public string? Router { get; set; }
    public string? Broadcast { get; set; }
}

public class DhcpStaticLease
{
    public string Hostname { get; set; } = string.Empty;
    public string MacAddress { get; set; } = string.Empty;
    public string IpAddress { get; set; } = string.Empty;
}
```

## Key Points

1. **Implement both interfaces**: Your module class should implement both `IMonolithModule` and `IModuleConfigGenerator`.

2. **Read from database**: Use your module's data store or Core API to read configuration from the database.

3. **Generate config files**: Create configuration files in standard system locations (e.g., `/etc/`).

4. **Validate configs**: Optionally validate generated configs before marking as successful.

5. **Return results**: Return a `ModuleConfigGenerationResult` with:
   - Success status
   - List of generated files
   - Whether service restart is needed
   - Any metadata

6. **Error handling**: Catch exceptions and return error information in the result.

## Service Restart

If your module requires a service restart after config generation:

1. Set `RequiresServiceRestart = true` in your implementation
2. The StartupManager will track which modules need restarts
3. Future Phase 3 will handle automatic service restarts

## Testing

To test your config generator:

1. Implement the interface in your module
2. Configure settings via WebUI
3. Reboot the system or manually call `startup.initialize` via API
4. Check that config files are generated correctly
5. Verify services start with the new configs

## Best Practices

1. **Include Monolith markers**: Always include `# Generated by Monolith FireWall` or `# BEGIN MONOLITH MANAGED` / `# END MONOLITH MANAGED` markers in generated files. This allows the system to:
   - Identify managed files
   - Clean old configs before generating new ones
   - Validate that files only contain Monolith-managed content

2. **Fresh generation**: The system automatically backs up and deletes old config files before generation (like pfSense), ensuring fresh configs on every boot.

3. **Backup existing configs**: The system automatically backs up existing configs before deletion. Your module doesn't need to handle this.

4. **Atomic writes**: Write to temp file, then move to final location (optional, but recommended for large files)

5. **Validation**: Always validate generated configs if the service supports it

6. **Logging**: Use `context.Logger` to log generation steps

7. **Idempotency**: Config generation should be safe to run multiple times

## File Management

The StartupManager automatically:
- **Backs up** old config files before deletion
- **Deletes** old managed config files before generating new ones
- **Validates** that generated files contain Monolith markers
- **Warns** if unmanaged files are found and will be overwritten

Backups are stored in:
- Module configs: `/var/lib/monolith-firewall/backups/module-configs/`
- Interface configs: `/var/lib/monolith-firewall/backups/interfaces/`
